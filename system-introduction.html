Overview

My Gemini Chat Web v2 is an upgraded AI assistant platform based on Homework 01. In the original version, the system mainly supported plain text conversation with the Gemini API. In v2, the project has been extended into a feature-complete chatbot system with long-term memory, multimodal image input, automatic model routing, tool use, and several practical interaction features. The goal of this upgrade is to make the chatbot capable of answering questions, remembering important user information, processing images, choosing suitable models automatically, and performing simple actions through tool calling.

Long-term Memory

The first major improvement is Long-term Memory. In the original chatbot, the model forgot everything after the conversation ended. In v2, a memory system is implemented on the server side using data/memories.json. Three APIs are added for memory management: GET /api/memories, POST /api/memories, and DELETE /api/memories/:id. The AI can automatically save important user information through tool calling, such as language preference or personal settings, and all saved memories are injected into the system prompt in later conversations so that the chatbot can maintain persistent context. In addition, the frontend provides a memory panel where users can manually add or delete memories.

Multimodal Support

The second improvement is Multimodal Support. The original system only accepted text input, while v2 allows users to interact with both text and images. Three image input methods are supported: clicking the upload button, dragging and dropping an image into the chat area, and pasting an image directly from the clipboard. The frontend converts the selected image into Base64 and sends it to the backend in JSON format. On the server side, the image is passed to Gemini together with the text prompt using inlineData. To support image input, the request size limit is increased from 1MB to 12MB. The chat interface also shows an image preview before sending the message.

Auto Routing

The third improvement is Auto Routing Between Models. In Homework 01, the user had to manually type the model name, which was inconvenient and error-prone. In v2, the input is replaced with a dropdown menu containing Auto, Gemini 2.0 Flash, Gemini 2.5 Flash, and Gemini 2.5 Pro. When Auto is selected, the server analyzes the complexity and length of the message and then chooses the most suitable model. General conversation is usually routed to Gemini 2.5 Flash for balanced speed and quality, while complex reasoning, coding, or long-form tasks are routed to Gemini 2.5 Pro for stronger capability. If a preferred model is temporarily unavailable, the fallback logic can retry with other available models, including Gemini 2.0 Flash. Each response also shows badges indicating which model was used and whether the result came from auto routing.

Tool Use / MCP-style Tool Calling

The fourth improvement is Tool Use / MCP-style Tool Calling. The original chatbot could only generate plain text and could not perform any actions. In v2, five Gemini function calling tools are defined on the server: get_current_datetime, calculate, save_memory, recall_memories, and web_search. These tools allow the AI to retrieve time information, perform safe arithmetic calculations, save user memory, search existing memories, and simulate web search results. A function-calling loop is implemented so that the model can call multiple tools continuously, up to five rounds, before generating the final response. The frontend also provides a switch for enabling or disabling tool use, and the response area displays which tools were used for that answer.

Other Useful Functions

The final part of the upgrade is Other Useful Functions. The chatbot now supports Markdown rendering using marked.js, so responses can display code blocks, tables, headings, lists, and blockquotes properly. An Export button is added so the entire conversation can be downloaded as a Markdown file. Each response also shows the API response time, helping users understand system performance. The interface also includes a Conversation Time Capsule feature for saving and restoring local chat snapshots. In addition, an extra practical feature called One-click Summary is added, which can summarize the conversation into goal, key points, decisions, open questions, and next steps.

File Changes

In terms of implementation, the main runtime changes are concentrated in four core files. server.js is extended with the memory system, multimodal support, auto-routing logic, tool definitions, execution loop, and new API endpoints. public/index.html is updated with image upload UI, memory management panel, model dropdown, tool toggle, Markdown styling, and export controls. public/app.js now handles image processing, memory management, Markdown rendering, export logic, and drag-and-drop or paste support. Finally, .gitignore is updated to exclude the data/ directory and generated report/media outputs so temporary or deliverable files are not committed to Git.

Conclusion

Overall, My Gemini Chat Web v2 transforms the original homework into a more complete and extensible AI chatbot system. It demonstrates not only frontend and backend integration, but also practical AI system design including memory management, multimodal input, automatic model routing, function calling, and conversation summarization.
